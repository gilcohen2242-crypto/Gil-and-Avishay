# Gil Cohen and Avhishay Website

Static GitHub Pages website for Gil Cohen and Avhishay Aiche's trading services.

## Files

- `index.html` contains the complete website, styling, and hero visual.
- `.github/workflows/deploy-pages.yml` publishes the site with GitHub Pages.
- `.nojekyll` keeps GitHub Pages from running Jekyll processing.
- `public-link.txt` stores the repository and public Pages link.

## GitHub Pages

After the workflow finishes, the site can be served from:

https://gilcohen2242-crypto.github.io/Gil-and-Avishay/
