# Gil Cohen and Avhishay Website

Static website for Gil Cohen and Avhishay Aiche's trading services.

## Files

- `index.html` contains the page markup.
- `styles.css` contains the responsive visual design.
- `script.js` powers the mobile navigation and contact form mail link.
- `assets/trading-hero.png` is the hero image.
- `.github/workflows/deploy-pages.yml` publishes the site with GitHub Pages.

## GitHub Pages

After this repository is published to the `main` branch, GitHub Pages can serve the site from:

https://gilcohen2242-crypto.github.io/Gil-and-Avishay/
